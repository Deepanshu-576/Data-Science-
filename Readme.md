Data Science with Python Internship – Week 1

Excel & Data Fundamentals.

This repository contains my work and learning outcomes from Week 1 of my Data Science with Python Internship.
During the first week, I focused on Excel fundamentals, data cleaning, data summarization, and basic statistical concepts. I also completed a sales analysis project using Excel Pivot Tables and a dashboard.

Week 1 Project

Sales Performance Analysis Dashboard
Objective
The objective of this project was to create an Excel Pivot Table Dashboard to analyze sales performance and identify important patterns in the sales data.
Analysis Performed
The dashboard focuses on the following key performance indicators:
Total Revenue
Sales by Category
Yearly Sales Trends
Department-wise Revenue
Dashboard Features
The Excel dashboard includes:
Pivot Tables
Sales summary
Category-wise sales analysis
Yearly sales trend analysis
Department-wise revenue analysis
Charts and visualizations
Interactive and easy-to-understand presentation of sales performance
Dataset
The project uses a sales dataset containing information related to products, categories, departments, sales, revenue, and dates.
The dataset was cleaned and organized before performing the analysis.
